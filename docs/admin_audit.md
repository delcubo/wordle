## 4. Сценарии: сколько действий сейчас

**A. Подтвердить слова на завтра во всех розыгрышах** (N активных розыгрышей)
- В каждом: выбрать розыгрыш в списке → прокрутить до блока «Слово на день N» (в Стандарте он 3-й
  после «Участников»; в Чемпионате ниже ещё 4 блока) → «Согласиться». Итого ≥2 действия + прокрутка, ×N.
- Сводного вида «что ждёт подтверждения» нет: приходится помнить, в каком режиме подтверждение
  вообще требуется (в Марафоне/Тай-брейке/паре нужно смотреть другие панели).

**B. Посмотреть, сколько доиграло и с каким результатом** (несколько раз в день)
- Стандарт, Бессрочный, На вылет: список участников (зелёный — сыграл, `3/6 · 22:16 · 0 сек`).
- Чемпионат, Марафон, Тай-брейк: в списке участников этой отметки нет — надо листать до таблицы
  или результатов (до 8 блоков вниз).
- Сводки по всем розыгрышам нет: чтобы обойти 5–6 розыгрышей — 5–6 переключений + прокрутка.

**C. Создать розыгрыш**
- Форма создания и форма настроек — одна большая секция внутри `TournamentPanel` (577 строк,
  13 полей состояния, ветвление по типу). Поля, не относящиеся к режиму, скрываются, но порядок и
  группировка общие для всех режимов; бонусы, команды, «игра за 3 место» живут в настройках,
  а часть параметров (планы длин, число игр в паре) — в других панелях, не в настройках.

## 6. Предложение для этапа 1 (на согласование)

**Новая вкладка «Сегодня»** (первая, открывается по умолчанию):

```
Сегодня, 31 октября
┌ Стандарт · день 4/10 ───────────────────────────────┐
│ Сыграло 7/12 · лучший 2/6 (#Ольга) · последний 22:16 │
│ Слово на завтра: ПЛИТА  [Подтвердить] [Другое] […]  │
└─────────────────────────────────────────────────────┘
┌ Марафон · слово 3 из 5 ─────────────────────────────┐
│ Доиграли 3/10 · в процессе 4 · не начали 3          │
│ Нужно внимание: слова 4–5 не подтверждены           │
└─────────────────────────────────────────────────────┘
```

- Одна строка/карточка на активный розыгрыш; на телефоне — карточки в столбец.
- Кнопка «Подтвердить» подтверждает слово без захода в розыгрыш; «Другое» меняет его; «…» открывает розыгрыш на вкладке «Слова».
- «Требует внимания»: неподтверждённые слова, неразобранные ничьи, пары без игры, розыгрыш без участников.
- Затем — подвкладки внутри розыгрыша (F4), существующие панели переезжают без переписывания.

Что это даёт именно вам: сценарии A и B сводятся к одному экрану вместо обхода каждого розыгрыша.
